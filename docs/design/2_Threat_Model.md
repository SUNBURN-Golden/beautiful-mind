# Threat Model (MVP 위협 모델링 10선)

Beautiful Mind MVP 시스템에 존재할 수 있는 다각적인 위협 요소를 분석하고, 이를 방어하기 위한 **'명시적 동의 및 프로세스 기반'**의 완화(Mitigation) 전략을 정의합니다.

1. **위협 [Privacy]: 사용자 동의 없는 위치/OSINT 정보 무단 수집**
   - **완화:** 모든 검증 모듈(위치, OSINT, 기기)은 실행 전/후로 명시적 동의(Opt-in) 절차 및 최신 토큰 검증을 수행. 동의 철회(Opt-out) 즉시 백엔드에서 해당 정보 접근 권한(Token) 파기 및 관련 로컬/세션 캐시 삭제.
2. **위협 [Privacy]: 민감 정보 제공 동의 철회 방해 및 지연**
   - **완화:** 철회 UI를 항상 최상단 및 설정 메뉴 최상단에 마찰 없이(Frictionless) 노출. 철회 요청 시 어떠한 마케팅성 확인 절차 없이 즉각적으로 권한을 블록하는 프로세스 적용.
3. **위협 [Abuse]: 악의적 유저들의 담합(Collusion)을 통한 신뢰도/검증 조작**
   - **완화:** OSINT 모듈 및 활동 로그를 분석하여 다계정/동일 IP 대역 등 담합 징후 탐지. 의심 로그 발생 시 자동 패널티 부과가 아닌, "검증 보류(Pending) -> 관리자 리뷰 또는 추가 소명 프로세스" 기반으로 전환하여 무고한 피해 방지 및 정밀 패널티 부과.
4. **위협 [Abuse]: 특정 타겟을 향한 악의적 허위 신고 (False Reporting / Sybil Attack)**
   - **완화:** 시스템 내 사용자의 신뢰도 점수(Reputation Score)를 가중 적용하여 신고 유효성 평가. 허위 신고가 누적/적발될 경우 신고자에게 '역패널티'를 부여하는 프로세스 도입. 신고 전에 '위증 및 허위 신고에 대한 법적 책임' 동의 징구(`docs/legal` 텍스트 연동).
5. **위협 [Spoofing]: GPS 및 기기 위치 조작 (Location/Device Spoofing)**
   - **완화:** 기기 무결성(OS 레벨 Device Integrity API) 교차 검증 및 네트워크 IP 기반 위치와 GPS 좌표의 정합성 대조. (해당 검증 또한 명시적 동의 획득 후 진행).
6. **위협 [Data]: DB 우위 접근을 통한 RLS 정책 우회 (Data Breach via RLS Bypass)**
   - **완화:** Supabase/PostgreSQL RLS 정책을 유저 UID 및 Role 기반으로 엄격히 체인화. 코어 모듈을 분리하여 각 모듈 전용 Role로만 DB에 접근토록 격리 (Principle of Least Privilege).
7. **위협 [Availability]: 코어 모듈(OSINT, 위치 등) 과부하 및 자원 고갈 공격**
   - **완화:** 모듈별 독립적인 Rate Limiting 및 서킷 브레이커 도입. 특정 모듈(예: OSINT)의 장애가 타 모듈(예: Auth)에 영향을 주지 않도록 마이크로 아키텍처 관점에서 코어 모듈 완전 분리.
8. **위협 [Compliance]: `docs/legal` 법적 텍스트 변조 및 우회 노출**
   - **완화:** 법률 관련 텍스트는 빌드 파이프라인 및 런타임에서 파일 시스템 읽기 전용으로만 접근. DB에 저장하지 않으며, API 응답 시 위변조 방지를 위한 무결성 체크 해시 적용.
9. **위협 [Auth]: 권한 상승(Privilege Escalation)을 통한 타인 데이터 탈취**
   - **완화:** API 명세에서 권한(Role)별 라우트를 철저히 격리. 클라이언트에서 전달되는 Role을 신뢰하지 않고 JWT 토큰 내 Claims 및 분리된 Auth 모듈을 통해 서버 스크립트에서 검증.
10. **위협 [Operation]: 부당한 패널티 자동 부과로 인한 선의의 사용자 피해**
   - **완화:** '자동화된 즉각적 영구 정지' 금지. 패널티는 [1차 경고 -> 2차 쿨다운 및 소명 기회 제공 -> 최종 서비스 제한] 의 명확한 3단계 프로세스를 거치도록 설계하여 시스템 오류로 인한 치명적 사용자 경험 훼손 방지.
