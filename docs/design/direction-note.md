# SoulBound Direction Note

## 1. Current Direction
Antiquarian direction was selected for Stage 5 visual locking. The human anchor is “a thirty-something translator reading a first-edition book in a Left Bank café in Paris”, and the resulting direction is documentary, restrained, and trust-first. SoulBound is not a dating app, social feed, luxury retail clone, or SaaS dashboard clone.

## 2. Palette Seeds
The retained palette families are saddlery-era orange, muted dark green, muted warm grey, and muted burgundy. For the authoritative token values, usage rules, and space logic, downstream readers must use `docs/design/tone.md`.

## 3. Retired Directions
- CMBYN ultramarine
- signature yellow
- SignatureMark component
- blending-ratio thinking
- cursive / handwritten font stack
- generic dating-app warmth
- generic social/community/feed grammar

## 4. Downstream Rule
`docs/design/tone.md` is the authoritative tone file. Future Phase 5.5 / 5.6 work must cite `tone.md`, and if `direction-note.md` and `tone.md` ever diverge, `tone.md` wins. This file is historical and contextual only; it is not authoritative for token values.

## 5. Scope Boundary
Phase 5.4a does not begin landing redesign, and Phase 5.4a does not begin dashboard redesign. Phase 5.4a exists only to restore traceability before redesign work begins.
