# 마이크로카피 덱 (한국어, 건조한 템플릿)

톤앤매너: 정중하지만 건조하게. 감정적 과장("환영합니다!", "대단하네요!")을 철저히 배제하고 사실 관계와 필수 행동만을 전달합니다.

## 공통 요소
- `Toast (기록됨)`: "해당 내용이 감사 로그로 안전하게 기록되었습니다."
- `Support CTA`: "도우미가 필요하신가요? 고객지원 센터로 문의하기"

## 1. 로그인 (`/login`)
- **헤드라인**: "접근을 위해 로그인하십시오."
- **설명**: "보안을 위해 본인 명의의 계안 정보만 이용할 수 있습니다."
- **버튼**: [계속하기] / [새 계정 생성]

## 2. 실명 인증 (`/onboarding/verify`)
- **헤드라인**: "본인 확인 절차를 진행합니다."
- **설명**: "명의 도용 방지를 위해 실명 인증이 요구됩니다. 인증 결과는 증적 로그로 남습니다."
- **버튼**: [인증 시작]
- **로딩**: "정보를 대조하고 있습니다..."
- **실패 (AUTH_REQUIRED / KYC_FAILED)**: "인증 기관의 무응답이거나 정보 불일치입니다. 다시 시도해주십시오."

## 3. 자격 증명 (`/onboarding/qualification`)
- **헤드라인**: "필수 자격 서류 제출."
- **설명**: "해당되는 문서 파일을 업로드하여 주십시오. (JPG, PDF 포맷 한정)"
- **버튼**: [서류 업로드] / [제출]
- **에러 (FILE_TOO_LARGE)**: "파일 크기가 제한 용량을 초과했습니다."

## 4. 약관 동의 (`/onboarding/consent`)
- **헤드라인**: "이용 약관 및 정보 수집 동의."
- **설명**: "서비스 진행을 위해 필수 약관 사항을 숙지하고 동의해주십시오."
- **버튼**: [동의하고 넘어가기]
- **에러 (DB_ERROR)**: "동의 내역 처리 중 오류가 발생했습니다. 다시 시도하십시오."

## 5. 전자 서명 (`/onboarding/sign`)
- **헤드라인**: "최종 계약 항목 및 서명 기입."
- **설명**: "문서 내용을 숙지하였으며 제출 시 법적 효력이 발생함에 상호 동의합니다. 지정된 영역에 서명하십시오."
- **버튼**: [서명 제출] / [서명 다시 쓰기]
- **영수증(성공 접수) 카피**:
  * "전자 서명 영수증이 생성되었습니다."
  * "문서 증명 해시: {hash}"
  * "타임스탬프: {time_bucket}"

## 6. AI 인터뷰 (`/interview`)
- **헤드라인**: "사전 1차 평가 인터뷰."
- **설명**: "제시된 질문에 빠짐없이 사실과 일치하게 답변해주시기 바랍니다."
- **버튼**: [답변 제출] / [종료 및 저장]

## 7. 대시보드 진입 대기 (`loading`)
- **로딩 텍스트**: "입력 정보와 감사 로그 증적을 최종 검토 중입니다..."
