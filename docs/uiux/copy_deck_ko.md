# 마이크로카피 덱 (한국어, Admission-First)

톤앤매너: 과장 없이 명확하고 절차 중심. 사용자가 "지금 상태"와 "다음 행동"을 즉시 이해하도록 작성한다.

## 공통 요소
- `Status Sync`: "현재 심사 상태를 동기화하고 있습니다."
- `Retry CTA`: "다시 시도"
- `Support CTA`: "도움이 필요하시면 고객지원으로 문의하세요."
- `Data Policy`: "원본 문서는 최종 결정 직후 즉시 파기되며, 최소 검증 클레임만 유지됩니다."

## 1. 진입 (`/`, `/login`, `/signup`)
- **랜드 헤드라인**: "입장은 자동 심사로. 신뢰는 검증으로."
- **로그인 설명**: "로그인 후 admission 상태(`/apply/status`)로 이동합니다."
- **회원가입 설명**: "계정 생성 후 admission 절차(`/apply/*`)를 진행합니다."

## 2. Admission 시작 (`/apply`)
- **헤드라인**: "엄격 심사형 Admission을 시작합니다."
- **설명**: "승인 전에는 핵심 기능이 잠기며, 필수 검증 단계를 완료해야 합니다."
- **버튼**: [Admission 시작]

## 3. 신원 검증 (`/apply/identity`)
- **헤드라인**: "1) 신원 검증"
- **설명**: "신원 검증 결과는 최소 정보로 기록됩니다."
- **입력 안내**: "본인확인 제공자의 검증 ID를 입력하세요."
- **버튼**: [신원 검증 완료 제출]
- **오류**: "신원 검증에 실패했습니다. 입력값과 인증 상태를 확인해 주세요."

## 4. 실재 인물 검증 (`/apply/liveness`)

- **설명**: "최종 저장값은 실재인물 검증 여부와 신뢰도 요약입니다."
- **체크 문구**: "원본 미디어 즉시 파기 정책에 동의합니다."
- **버튼**: [실재 인물 검증 완료 제출]

## 5. 분리 동의 (`/apply/consents`)

  - "처리 상태"
  - "최종 상태"

- 해당 경로 진입 시 현재 admission 상태에 맞는 경로로 자동 리다이렉트된다.
